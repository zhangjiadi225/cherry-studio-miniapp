# 模型布景 v0.2 开发验收报告

> 历史报告：其中的默认主体与摄影棚方案已被 v0.3.7 的“纯黑背景 + `Y=0` 网格 + 无内置模型”空工作区取代。

> 日期：2026-08-31  
> 范围：默认场景、无模型对话、界面精简、开发构建与打包

## 本轮结果

- 打开后由 Skenora 直接渲染默认主体、展台、地面、环境、三点灯光和轨道镜头。
- Cherry AI 对话不再检查是否已经导入模型；当前 `subjectEntityId` 始终指向默认主体或用户主动导入的本地模型。
- 默认主体支持安全的变换和外观修改；本地模型继续限制为变换与显隐，不能被 AI 替换资源或改写文件身份。
- 本地 GLB/glTF 导入保留为可选的主体替换操作，失败时默认场景或上一模型仍可使用。
- UI 删除空场景遮罩、场景标签、说明脚注、对象列表、修改域卡片和技术性回执，只保留 3D 视口、对话、常用指令、导入、导出、撤销和视角控制。
- 视觉层级参考 Linear 的紧凑产品界面：单一强调色、细边框、低层级表面和 8–12px 圆角，没有装饰渐变或悬浮营销卡。

## 宿主内人工验收

1. 打开小程序，不进行任何导入，确认默认主体和摄影棚可见。
2. 依次使用“暖色夜景”“柔和灯光”“近景”“旋转主体”，确认四轮都能提交并产生可见变化。
3. 导入一个本地 GLB，确认默认主体隐藏、模型自动落地取景，后续对话改为操作本地模型。
4. 确认窄窗口下对话区移到视口下方，核心按钮仍可使用。

按仓库规则，本轮未代替用户执行 Cherry Studio 内手工 UI/WebGL/E2E 验收。
