# 本地效果方案

版本：0.6.0 · 更新日期：2026-09-03 · 实现完成，运行验收待用户执行。

## 产品闭环

打开“方案”页 → 导入自己的 GLB/glTF → 点击效果卡片 → 用机位、背景、灯光微调 → 撤销或导出场景。也可以先为空场景布景再导入模型。整个流程无需 AI 模型、API Key、MCP 或额外网络素材。

| 方案 | 确定性设置 | 使用意图 |
| --- | --- | --- |
| 柔光白棚 | 暖白背景、中性补光、暖主光、轻阴影 | 商品、手办 |
| 深色产品棚 | 深灰背景、较低补光、暖主光、冷轮廓光 | 结构和材质展示 |
| 黑金轮廓 | 黑色背景、暖金灯光、轻泛光与暗角 | 氛围展示；不会把材质改成金属 |
| 冷蓝科技 | 蓝黑背景、冷色灯光、轻泛光 | 科技产品展示 |
| 透明素材 | 透明背景、无地面、中性三点灯光 | 为后续素材制作准备场景；当前没有 PNG 导出 |

卡片用 CSS 绘制风格示意，不冒充真实模型效果。视口始终渲染用户自己的模型；无内置样品、无 AI 生成图、无自动素材下载。预设参数是产品默认值，不承诺所有模型都有相同视觉效果。

## 修改范围

每套方案只更新 environment、ground、fog、weather、camera、postProcess，以及 `workspace-fill`、`workspace-key`、`workspace-rim` 三个应用灯光。缺失的应用灯光会重建，已有的会更新，其他自定义灯光不删除。

不改变实体、模型资源、模型变换、材质及材质绑定、相机路径、动画和 Flow（场景行为流程）。应用前停止动态预览，不自动重启。方案重置完整基础后期并关闭雾与天气，避免上一套效果的后期残留。

快捷机位覆盖正面、左前、右前、俯视；有可用主体时额外执行视口取景。视口取景是 Skenora 的临时相机适配，不额外生成文档事务。方案的固定机位保存在文档中，运行时适配后的取景距离不作为额外的保存契约。模型的“正面”按世界坐标约定，不推断模型朝向。

背景色板提供纯黑、石墨灰、暖白、暖棕、深蓝、透明，仅替换背景，不删除已有地面。透明素材方案才会同时关闭地面。棋盘格仅属于界面，不写入场景。

灯光滑杆在松开或键盘确认数值变化后提交；拖动期间只显示数值，不逐帧写入场景。通常范围为 0–2.5；若已有灯光更强，则保留其真实上限。缺失/禁用的灯光不可微调，用户可重新选择方案恢复。

## 执行与状态

- `scene-recipes.ts` 拥有产品方案、纯数据计划构造和本地提交入口，不调用 Cherry AI。
- `scene-controller.ts` 从公开 `inspectScene()` 获取 SceneRevisionToken（场景版本令牌，包含场景 ID、版本与文档哈希）。
- `validatePlan()` 根据当前文档与运行环境检查字段、预算、能力和引用；不可用方案拒绝提交并展示诊断，不静默降级。
- `applyPlan()` 使用同一版本令牌、唯一操作键和 strict（严格模型加载）策略。一个操作只提交一次，冲突不自动重放。
- 文档 committed（事务已提交）与 projection（画面更新）分开反馈；部分模型失败、取消或投影失败时，仍保存已提交结果并保留撤销入口，不自动回滚或重复应用。
- `scene-result.ts` 统一 AI 与本地操作的画面警告文案。
- 本地镜头同步位置与轨道参数；AI 在已有轨道参数时若只修改位置/目标，会被产品策略拒绝并进入一次修复，避免“已修改但画面不动”。
- 操作期间串行阻止新方案、导入、AI、历史操作和预览启动；待确认 AI 提案会锁定本地修改，避免版本失效。隐藏应用取消可取消的提交并暂停预览。

存储升级为 `model-stage-state-v6`，依次迁移 v5、v4、v3、v2，不删除旧存档键。新状态保存七类无需用户文件的布景参数、标准漂浮预设密度、当前方案 ID、界面状态、对话和最近提交记录。提交记录中的计划 JSON、操作 ID、版本、变化 ID、投影状态与失败模型 ID 仅供回看，不在启动时重放，也不作为新场景的状态或 AI 上下文。手动微调、AI 修改、撤销/重做和重置镜头会清空方案选中标记。

### Skenora 0.1.3 环境氛围

- 包版本及锁文件统一为 npm 发布的 0.1.3；只显式导入公开 `@skenora/sdk/particles`，不复制上游贴图或预设数值表。
- `scene-particles.ts` 使用 `createWeatherPreset()`、`createParticlePreset()` 和 `getBuiltinParticleTextureAsset()`。初始化安装 `createBuiltinParticleResourceProvider()`，并注册三张固定纹理的元数据；图片模块由提供器在实际使用时加载，不访问远程图片服务。
- 雨幕/飘雪写入普通 weather；漂浮使用 `model-stage-ambient-drift` 专用粒子实体。四个选择互斥切换本应用的氛围，其他自定义粒子不删除。非粒子占用专用 ID 时拒绝操作。
- 密度是相对上游默认发射速率的 0–2 倍，仅在松开滑杆或键盘确认后提交。0 不瞬间清除已有粒子；这些粒子会按生命周期消失。已有天气超出本地密度范围时显示真实值并提供恢复默认，不假称仍是标准值。
- 雨雪是 Skenora 的即时环境效果，`enabled` 后开始运行；包括重启恢复启用的内置雨雪。漂浮遵循 Editor 的手动预览，只在点击视口“预览”后播放。停止预览不会关闭雨雪，选择“关闭”才关闭本应用氛围。隐藏应用仍暂停整个 Runtime。
- 一次选择、恢复默认或密度调整都是原有 ScenePatch 提交流程，具备版本冲突检查、能力校验、提交/画面结果区分和撤销。AI 不可用时全部本地控件仍可用。
- AI 上下文包含内置纹理逻辑 ID 和上游工厂返回的原生字段示例，不含资源定位器、PNG 字节或 MCP 连接。示例不是设备能力证明，仍按 `inspectScene()` 的实际能力校验。
- 不新增自定义纹理导入 UI、完整粒子编辑器或 WebGPU 模拟器。天气没有碰撞、积雪、水花、湿润材质或体积雾；不同尺寸模型需要真实宿主验收。

本次 MCP 连接的资源目录仍是旧快照，`docs.particle-presets` 返回不存在；新文档在上游和 0.1.3 tooling 中已有定义。实现依据实际 npm 0.1.3 SDK 声明/源码及上游粒子文档，不将旧 MCP 目录当成新包能力清单，也没有修改全局 MCP 配置。

UI 沿用现有 Cherry 主题、按钮、滑杆与禁用/焦点规则，参考 Linear 的紧凑分组与单一强调色，不引入新视觉主题。

### 重启恢复边界

| 数据 | 行为 |
| --- | --- |
| 背景、环境、地面、雾、天气、文档镜头、灯光、后期 | 按字段白名单提取并逐类校验；无效类别回退，其他类别保留 |
| 外部图片、环境贴图、天气贴图 | 背景回退纯色、外部环境贴图关闭；无法恢复贴图的天气关闭并提示。纯参数天空可保留 |
| 三张包内置粒子贴图 | 启动时从 SDK 固定重建资源注册，只允许这些逻辑 ID 跨会话恢复，不信任旧资源定位器 |
| 标准应用漂浮预设 | 只保存 0–2 倍密度；从 SDK 重建专用实体，等待预览。自定义变换/属性/父子绑定使其不再满足恢复条件 |
| 方案选择、页签、场景设置节点选中与展开 | 恢复；已不存在的节点回退，模型节点不会跨会话保留 |
| 模型文件、模型实体、变换、材质和绑定、其他实体 | 仅当前会话；重启从空模型工作区开始，重新导入使用新 ID 和默认对齐 |
| 对话、最近 AI/本地提交 | 仅供查看；重启或替换模型后，AI 只接收新会话对话与当前场景 |
| Flow、动画、镜头路径、待确认提案、撤销/重做栈、播放状态 | 不恢复，不自动执行 |

`stage-settings.ts` 先从旧 JSON 选择设置字段，再交给 Skenora 校验，构造不含历史模型的新文档；只添加 SDK 固定内置资源和可选标准漂浮预设。失效文件路径不会到达渲染初始化。自动保存与显式导出相互独立：导出仍输出当前完整场景 JSON，不含模型字节；导出里的内置粒子引用在外部重载时也需要同版本提供器。UI 保存做短延迟合并，宿主写入串行执行；启动未完成或失败时不保存，存档读取异常时临时使用空工作区，不覆盖旧存档。关闭时仅尽力补存，不能承诺强制结束进程时保留最后瞬间的操作。

这里的“应用内部交互”指面板选择、展开和布景参数操作；不是绑定模型的点击流程或动画。Undo（撤销）历史只属于当前会话。

## 待用户执行的验收

- [ ] AI 未配置/未授权时，方案、背景、机位和灯光仍然可用；不会发起 AI 请求。
- [ ] 首次启动默认显示“方案”；三个页签支持鼠标和左右/Home/End 键，明暗主题与窄窗口可用。
- [ ] 用一个真实模型依次应用五套方案，确认每次一个撤销步骤，连续切换不叠加雾、天气或后期。
- [ ] 方案不改变模型及材质；删除应用灯光后再选方案会重建，自定义灯光保留。
- [ ] 大/小尺寸模型取景正常；四个机位角度不同，不被旧的轨道参数覆盖。
- [ ] 拖动滑杆只在松开后提交；当前数值与场景树一致，拒绝提交后恢复真实数值。
- [ ] 背景/灯光微调、AI 修改、撤销/重做后取消“已选”，场景树及节点属性同步。
- [ ] 预设不会自动播放 Flow/动画；预览中应用方案会先停预览。
- [ ] AI 待确认或其他操作执行期间，本地控件禁用；隐藏时不会重复提交。
- [ ] 对能力不可用、版本冲突与模型投影失败分别显示真实结果，不把已提交说成未修改。
- [ ] v2/v3/v4/v5 存档可迁移到 v6；重启不请求旧模型文件、不出现模型加载失败，场景树没有历史模型或材质绑定。
- [ ] 导入模型、调整背景/灯光/地面/文档镜头/后期后重启：布景保留，模型为空；再次导入仍使用该布景，且没有旧变换或材质绑定。
- [ ] 切换页签并展开场景设置节点后重启能恢复；上次选中的模型节点安全回退。
- [ ] 含外部背景/环境/天气贴图的旧存档能启动并提示回退；破损的某一类设置不影响其他有效设置和历史记录恢复。
- [ ] 旧对话标记为历史；重启/替换模型后的 AI 请求不包含旧对话，历史 JSON 只有查看入口。
- [ ] AI 待确认、撤销历史与动态预览状态不跨重启恢复，不自动执行旧计划。
- [ ] 连续切换页签并调整布景后重启，以最后一次保存为准；读取存档失败不会用默认状态覆盖旧存档。
- [ ] AI 未授权/未配置时雨幕、飘雪、漂浮光点仍可选；雨雪即时出现，漂浮仅点击“预览”后出现。
- [ ] 密度 0/0.5/1/2、恢复默认、关闭、连续切换、撤销/重做均以真实文档为准；没有重复粒子实体或意外移除用户模型。
- [ ] 隐藏时雨雪与漂浮均停止渲染；重新显示不自动启动漂浮预览。
- [ ] 雨雪设置和标准漂浮密度重启后可恢复，内置贴图正常；模型不恢复，漂浮不自动播放；自定义粒子不被当作标准预设保存。
- [ ] AI 可引用上下文中的内置纹理；没有随意创建 resource，也没有把本地路径或 PNG 字节发送给模型。
- [ ] 无离站图片请求；Cherry 的沙箱允许包内图片模块和作用域内 Blob 纹理加载；明暗背景与窄窗口下控件及粒子可用。
- [ ] 透明背景显示辅助棋盘格；导出文件仍为场景 JSON，不误称图片或包含模型的完整工程。

本次仅做源码静态检查；未运行类型检查、构建、测试、打包或交互验收。视觉参数需以 Cherry Studio 中的真实结果为准。
